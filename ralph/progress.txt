# Ralph Progress Log
Started: Mon Mar  2 05:35:09 PM CST 2026

## Codebase Patterns
- Sidebar uses `$props()` interface pattern with optional props defaulting to false/undefined
- Mobile responsive uses Tailwind `md:` breakpoint prefix exclusively — no custom @media queries
- State modules in `ui/src/lib/state/` export functions wrapping `$state` variables
- Use `lucide-svelte` for all icons (Menu, X, Terminal, Server, etc.)
- Backdrop overlays use `<button>` with `tabindex="-1"` for click-to-dismiss (accessible)
- Gate mobile-only rendering with `mobileOpen` prop checks alongside `collapsed` checks
- Playwright browser install not available on Fedora — manual browser testing needed
- Direction-switching animation: `translate-y-full md:translate-y-0 md:translate-x-full` (when closed) to animate different axis per breakpoint
- Bottom sheet pattern: `fixed bottom-0 left-0 right-0 h-[70vh] rounded-t-xl` + `md:absolute md:...` for responsive panel
- Mobile detection: `ui/src/lib/state/mobile.svelte.ts` exports `isMobile()` — use for JS-level responsive logic (e.g., overriding $derived grid classes in SplitView)
- Svelte 5 has built-in `MediaQuery` class in `svelte/reactivity`, but project uses custom `$state` pattern for consistency with other state modules
- CRUD pages: convert tables to card grids for mobile — `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` with card pattern `border rounded-lg p-4 flex flex-col gap-2`
- Icon-only buttons on mobile: wrap text in `<span class="hidden md:inline">Text</span>`
- Page headers: use `flex flex-wrap items-center justify-between gap-2 px-4 md:px-6` for responsive stacking
- Touch targets: use `p-2 md:p-1` (or `py-2.5 md:py-1.5`) for WCAG 2.5.5 compliant mobile touch targets
- Safe-area insets: use `pb-[env(safe-area-inset-bottom)]` with `md:pb-0` reset; requires `viewport-fit=cover` in meta tag
- Eliminate 300ms tap delay: add `touch-action: manipulation` to body in app.css
