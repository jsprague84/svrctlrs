## Codebase Patterns
- Sidebar uses `$props()` interface pattern with optional props defaulting to false/undefined
- Mobile responsive uses Tailwind `md:` breakpoint prefix exclusively — no custom @media queries
- State modules in `ui/src/lib/state/` export functions wrapping `$state` variables
- Use `lucide-svelte` for all icons (Menu, X, Terminal, Server, etc.)
- Backdrop overlays use `<button>` with `tabindex="-1"` for click-to-dismiss (accessible)
- Gate mobile-only rendering with `mobileOpen` prop checks alongside `collapsed` checks
- Playwright browser install not available on Fedora — manual browser testing needed
- Direction-switching animation: `translate-y-full md:translate-y-0 md:translate-x-full` (when closed) to animate different axis per breakpoint
- Bottom sheet pattern: `fixed bottom-0 left-0 right-0 h-[70vh] rounded-t-xl` + `md:absolute md:...` for responsive panel
