# Ralph Progress Log
Started: Thu Mar 20 2026

## Codebase Patterns
- Branch: ralph/mobile-responsive — terminal/SSH management tool, NOT the job-based system on main
- Rust workspace has 4 crates: core, database, server (scheduler exists on main but not active here)
- SvelteKit 5 frontend in `ui/` — Svelte 5 runes ($state, $derived, $effect), Tailwind CSS v4, adapter-static
- State modules in `ui/src/lib/state/*.svelte.ts` export getter functions wrapping `$state` variables
- Database queries in `database/src/queries/` — use `anyhow::Context` for error handling (some modules use inconsistent .map_err pattern)
- Credential values encrypted at rest with AES-256-GCM via `core/src/encryption.rs`
- `list_credentials()` uses SQL CASE to redact values at query level — never loads secrets for list operations
- Dynamic SQL updates use `sqlx::QueryBuilder` with proper typed `.push_bind()` — no more String::push_str + Vec<String>
- Two SSH libraries: `async-ssh2-tokio` (non-interactive, terminal.rs) and `russh` (PTY/interactive, terminal_pty.rs)
- ssh.rs uses NoCheck for host keys (insecure), but terminal.rs implements proper TOFU with server_host_keys table
- Backend quality checks: `cargo clippy --workspace -- -D warnings && cargo test --workspace`
- Frontend quality checks: `cd ui && npm run check && npm run build`
- Icon library: lucide-svelte — all icons now use lucide-svelte consistently
- Mobile breakpoint: md (768px), mobile detection via `ui/src/lib/state/mobile.svelte.ts`
- CRUD pages have loading/error/empty states with Retry button — use `extractErrorMessage()` from `$lib/utils/error.ts`
- API client handles non-JSON error responses and logs logout failures
- Toast system cancels timers on manual dismissal via Map<id, timer>
- TerminalPane cleanup already handled via disconnect() which clears reconnectTimeout
- `extractErrorMessage()` is ApiError-aware: extracts body.error.message from backend responses
- Modal has focus trap (Tab/Shift+Tab cycle within content, Escape closes, restores focus)
- Button: focus-visible outline, cursor-not-allowed on disabled (no pointer-events-none conflict)
- Color contrast: --color-text-muted meets WCAG AA 4.5:1 in both dark and light themes
