# UI Polish & Settings Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the legacy settings page with a tabbed UI (General, Notifications, Quick Commands, About), add quick command CRUD, profile edit, default profile auto-load, and purge legacy settings.

**Architecture:** Complete rewrite of `/settings` page using 4 dedicated tab components. Quick commands management lives inside the Settings > Quick Commands tab. Profile edit via a new modal triggered from the sidebar. All backend APIs already exist — this is purely frontend + one database migration.

**Tech Stack:** Svelte 5 runes, SvelteKit, Tailwind CSS v4, lucide-svelte icons, existing API client + state modules

**Spec Reference:** `docs/superpowers/specs/2026-03-21-ui-polish-design.md`

**Branch:** `ralph/ui-polish` from `ralph/phase5-rstify`

## Task 8: Default Profile Auto-Load

**Files:**
- Modify: `ui/src/routes/+page.svelte`

- [ ] **Step 1: Add $effect for default profile auto-load**

In `+page.svelte`, add a `$effect` that watches for profiles to load and applies the default:

```typescript
$effect(() => {
    const allProfiles = profilesState.getProfiles();
    const currentTabs = terminalState.getTabs();
    if (allProfiles.length > 0 && currentTabs.length === 0) {
        const defaultProfile = allProfiles.find(p => p.is_default);
        if (defaultProfile && defaultProfile.pane_configs) {
            const serverNames: Record<number, string> = {};
            for (const s of serversState.getServers()) {
                serverNames[s.id] = s.name;
            }
            terminalState.applyProfile(
                defaultProfile.layout as LayoutMode,
                defaultProfile.pane_configs,
                serverNames
            );
        }
    }
});
```

Import `profilesState` if not already imported. Import `LayoutMode` from types.

This only fires when tabs.length === 0 (initial load) and profiles are populated.

- [ ] **Step 2: Remove the manual initial tab creation**

The existing code creates a default empty tab:
```typescript
if (tabs.length === 0) {
    terminalState.createTab(null, null, 'pty');
}
```

Move this inside the $effect as the fallback when no default profile exists:
```typescript
if (defaultProfile && defaultProfile.pane_configs) {
    // apply profile...
} else {
    terminalState.createTab(null, null, 'pty');
}
```
